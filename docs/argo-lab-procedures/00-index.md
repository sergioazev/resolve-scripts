# Argo Lab Procedures

Post-production procedures manual for Argonautas. The companion to
`docs/post-production-audit.md`: **the audit asks questions; this manual gives
Argonautas' standard answers.** Once a standard is written here, the audit of a
new project reduces to "are we following the manual, and what are this
project's deltas?"

## How to maintain this manual

- Every procedure has one owner; every standard records *why* it was chosen.
- `[DECIDE: …]` marks a house standard not yet set — resolving these is the
  main editorial work remaining. `[CALIBRATE: …]` marks an industry
  rule-of-thumb figure to be replaced with Argonautas actuals.
- When a production teaches a lesson, it enters chapter 6 as a case study and,
  if recurrent, becomes a standard in chapters 2–3 and an item in the audit.
- Scripts in this repository automate procedures in this manual; each script's
  documentation must name the procedure it serves.
