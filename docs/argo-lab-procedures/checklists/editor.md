# Editor — one-page checklist

**[G2] Before shooting**
- [ ] Shot list reviewed: said in writing what coverage the cut will actually need
- [ ] Scenes relying on the edit for emotional lifting flagged, coverage agreed
- [ ] Version naming scheme and change-list procedure agreed with post supervisor
- [ ] Turnover spec known now (AAF/XML/EDL, handles) — cut with it in mind

**[P] During production — you co-own the weekly review**
- [ ] Cuts depending on coverage not yet shot: count them, report them weekly
- [ ] Scenes that don't cut reported while pickups are cheap (3.3 decision tree)
- [ ] Assembly feedback to set within the week — silence hides problems until lock
- [ ] Temp media logged as it enters the cut: temp VFX, temp music, archival
- [ ] Cutting only from managed project media — nothing dragged in from desktop
- [ ] Every cut version named to scheme; change list per cut-to-cut revision

**[PL] At picture lock**
- [ ] Overlong scenes and front-loaded exposition resolved — not left "for the mix to fix"
- [ ] Timeline clean for turnover: no offline media, no unlogged temp, no disabled
      surprise layers
- [ ] Roundtrip test cut provided to finishing; relink verified before lock declared
- [ ] Contingency prototypes (scene-out versions) built for anything flagged at risk
