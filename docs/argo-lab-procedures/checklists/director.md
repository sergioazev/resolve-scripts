# Director — one-page checklist

**[G1] Decide before greenlight (on the page, with the writer)**
- [ ] Scenes that will almost certainly be cut down — shorten them now
- [ ] Scenes that exist only to deliver information — find another way
- [ ] Parallel storylines: is the complexity earning its assembly cost?
- [ ] Flashbacks/non-linearity: would straightening lose anything real?
- [ ] Hero VFX shots: which ones is the film actually about?
- [ ] Scenes with digital doubles / de-aging / face replacement — confirmed necessary?

**[G2] Before shooting**
- [ ] Editor's coverage feedback on the shot list heard and answered
- [ ] Scenes where the edit does heavy emotional lifting: coverage plan agreed
- [ ] Sound consulted on masks/costumes, overlapping dialogue, loud locations —
      performance-hostile ADR identified now, not in the mix
- [ ] Sequences where silence does dramatic work: location sound plan protected

**[P] During production**
- [ ] Assembly feedback reviewed while pickups are still cheap — a missing
      insert costs minutes today, an ADR session later (case 6.1)
- [ ] Performance/coverage concerns from editorial answered same week

**[PL] At picture lock**
- [ ] Front-loaded exposition resolved — last cheap moment to fix pace
- [ ] Contingency decided in writing for any scene that may not survive
- [ ] Lock means lock: post-lock changes go through change lists and cost real money
