# Post Supervisor — one-page checklist

You own gates [G2] and [PL], co-own [P] weekly. The full audit is your
document; this page is only the spine.

**[G1] Support the greenlight**
- [ ] Audit run on script/schedule/budget; Green-Light Review drafted for producer

**[G2] Lock before shooting**
- [ ] Camera test through the entire real pipeline — dailies, editorial, VFX
      roundtrip, grade, deliverable — passed before day one
- [ ] Color Pipeline Sheet authored and distributed; Camera Metadata Sheet in use
- [ ] Naming/timecode/metadata standards agreed across camera, sound, editorial, VFX
- [ ] Backup policy (3-2-1 + checksums) with named data owner; storage projected
- [ ] Finishing pipeline, turnover specs, and version discipline confirmed with
      every department
- [ ] Delivery Matrix opened — no TBD rows; accessibility and mastering scheduled
- [ ] Cloud/remote editorial and review tooling tested with real media
- [ ] Security (TPN/NDAs/watermarking) and AI policy communicated
- [ ] Risk register opened; no red passes the gate

**[P] Weekly, without exception**
- [ ] Risk register re-scored; movement recorded; stuck reds escalated
- [ ] Backups verified; dailies keeping pace; conform spot-checked on real scenes
- [ ] VFX Shot Log drift, ADR Forecast, Music Clearance Tracker, temp-media log reviewed
- [ ] Screeners watermarked and access-logged

**[PL] Verify at picture lock**
- [ ] Picture Lock Report: all ten items PASS or waived in writing
- [ ] Editorial looks vs finishing math confirmed; textless verified
- [ ] Turnovers accepted by sound, music, VFX, color; change-list procedure live
- [ ] Legal review of locked cut complete (music, artwork, trademarks, AI disclosure)

**After delivery**
- [ ] QC Reports archived; Archive Verification Sheet complete before storage release
- [ ] Closed risks with real costs fed back into chapters 5–6
