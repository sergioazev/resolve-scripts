# Sound Supervisor — one-page checklist

**[G1] Feed the greenlight**
- [ ] Custom sound design needs identified from the script (vs library)
- [ ] Original score vs library flagged for the budget

**[G2] Lock before shooting**
- [ ] Recording spec locked: sample rate/bit depth, iso track layout, TC sync
      method (tested in the camera test), sound report format
- [ ] Sound scout on flagged locations: noise, vehicles, water, wind
- [ ] Consulted on masks/costumes, staging of overlapping dialogue
- [ ] ADR-hostile performances identified (children, non-actors, emotional peaks)
      and escalated — these are production problems, not mix problems
- [ ] Walla/crowd build scope estimated; room tone discipline agreed with set
- [ ] Silence-driven sequences: location sound protection plan agreed
- [ ] Mix, M&E, and stems requirements taken from the Delivery Matrix **now**

**[P] Weekly during production**
- [ ] Dailies audition: is location sound clean, or is the ADR list growing?
- [ ] ADR Forecast updated: scenes, lines, actors, availability windows, cost
- [ ] Sound reports arriving complete; gaps chased through the DIT/AE chain

**[PL] At picture lock**
- [ ] Turnover accepted: track layout, handles, reference export verified
- [ ] ADR Forecast final: sessions booked against actor availability, not hope
- [ ] Mix schedule confirmed against the real lock date — with the fix window
      QC will need
- [ ] M&E built alongside the mix, not reverse-engineered after
