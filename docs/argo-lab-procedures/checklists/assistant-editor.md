# Assistant Editor — one-page checklist

**[G2] Before media arrives**
- [ ] Project structure built to house convention (bins, naming, collaborative settings)
- [ ] Ingest spec confirmed with DIT: proxy format, naming, metadata fields, LUTs
- [ ] Turnover requirements (handles, AAF/XML/EDL flavors) tested with finishing

**[P] Daily during production**
- [ ] Ingest to convention; verify metadata actually arrived (scene/take/camera —
      searchable, not just present)
- [ ] Sync verified against sound reports; discrepancies reported same day
- [ ] Media accounted for against DIT manifests — gaps chased the day they appear
- [ ] Temp-media log maintained: every temp VFX, temp music, archival element
      logged the day it enters the cut
- [ ] Version hygiene enforced: cuts named to scheme, change lists generated,
      old versions archived not deleted
- [ ] Conform spot-checks prepared when post supervisor requests them

**[PL] At picture lock**
- [ ] Timeline prepped for turnover: tracks organized, disabled clips resolved,
      no offline media, temp log reconciled
- [ ] Turnover packages exported to spec for sound, music, VFX, color — with
      reference exports
- [ ] Relink/roundtrip test sequence delivered to finishing; failures documented
- [ ] Dialogue list / continuity support materials prepared for subtitling and
      accessibility vendors
