# DIT — one-page checklist

**[G2] Before day one**
- [ ] Camera test executed with post: actual bodies, formats, frame rates,
      through dailies → editorial → grade → deliverable
- [ ] Color Pipeline Sheet received; monitoring LUTs installed and versioned
- [ ] Offload tooling configured: checksum type, report format, 3-2-1 targets
- [ ] Naming convention and Camera Metadata Sheet format agreed with editorial
- [ ] Storage plan (on-set + off-site) sized from shoot ratio with headroom

**[P] Every shooting day**
- [ ] Every card offloaded with checksum verification — no "copy looked fine"
- [ ] Three copies exist before any card is released for reuse; release logged
- [ ] Camera Metadata Sheet filled per unit: formats, frame rates, LUTs, TC sync
- [ ] Sound reports collected and passed with the day's media
- [ ] Dailies to spec, same-day; LUT changes documented, never silent
- [ ] **Rogue sources (drone, phone, crash cam): nothing bypasses the cart.**
      Same-day pipeline test per 3.1 decision tree; deviation logged
- [ ] Offload backlog reported the day it starts — not when it's three days deep

**[Wrap]**
- [ ] Full media manifest with checksums handed to the data owner
- [ ] All copies accounted for against the manifest before the cart wraps
